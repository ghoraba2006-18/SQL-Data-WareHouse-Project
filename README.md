# SQL-Data-WareHouse-Project
 # 📊 SQL Data Warehouse Project

## 📌 Overview

This project demonstrates the design and implementation of a **Data Warehouse using SQL**.

The goal is to transform raw data into a clean, structured, and analytics-ready database for reporting and business analysis.

## 🛠️ Technologies

* SQL
* MySQL / SQL Server
* Git & GitHub
* Power BI

## 🏗️ Architecture

The project follows a **Bronze → Silver → Gold** architecture:

```text
Raw Data
   ↓
Bronze Layer
   ↓
Silver Layer
   ↓
Gold Layer
   ↓
Analytics & Reporting
```

### Bronze

Stores raw data from the source systems.

### Silver

Cleans and transforms the data by handling duplicates, NULL values, incorrect formats, and other data-quality issues.

### Gold

Contains business-ready data organized using a **Star Schema** with fact and dimension tables.
